### Coupling finding (the crux of this task)
- The manifest lists `org.chimeramc.client.ui.activities.*`, but those files physically live in
  `app/src/main/java/org/chimeramc/client/launcher/ui/activities/` — i.e. **the directory tree does
  not match the package tree** for the whole `launcher/ui` tree (package decls are
  `org.chimeramc.client.ui.*`). Operate on FILES, never assume dir==package.

- **No engine/core package imports the UI**, but **41 kept files reference deleted UI symbols**

## TRAP: regex `</style>` removal over-matched
Removing `Widget.Caramel.QuickDock` (a **self-closing** `<style name="…" parent="" />`) with a
`re.search(r'<style name="X".*?</style>')` pattern ran PAST it to the next real `</style>` and ate
the `TextAppearance.Caramel` base style + its doc comment. Recovered by restoring the block from
`git show HEAD:…`. Lesson: match self-closing styles explicitly (`/>` vs `</style>`).
